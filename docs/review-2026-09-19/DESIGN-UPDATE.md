# Дизайн и изображения предметов — v0.2.4

## Изменения

Основной экран объединяет аккаунты, режим запуска, поиск и доступ к выбранному аккаунту. Можно переключаться между карточками и компактными строками; выбор вида сохраняется локально. В панели аккаунта доступны текущий Steam Guard, копирование кода, состояние сессии и переход к подтверждениям. Экспорт, восстановление файлов и удаление доступны через меню «Другие действия».

Навигация: аккаунты, общая очередь подтверждений, управление Steam Guard, настройки. Сохранены существующие мастера входа, привязки, импорта, мастер-пароль, восстановление сессии и проверки перед запуском игры. Системный Segoe UI работает без Google Fonts; моноширинный шрифт используется для кодов и идентификаторов. Убраны scanline и пиксельная обработка изображений. Окно сохраняет минимальный размер 760×520, большие списки прокручиваются.

## Изображения и состав обмена

- `mobileconf/getlist` уже возвращал `icon`, но прежний компонент рисовал только символ типа операции. Продажи теперь показывают эту картинку рядом с заголовком, ценой и названием, которые вернул Steam.
- У трейда `icon` может быть аватаром партнёра. Он оформлен как аватар; изображения предметов находятся в отдельном раскрываемом составе.
- Новый `auth_confirmation_details` работает через существующие workspace lease, проверку выбранного аккаунта и механизм восстановления сессии. Сначала находит подтверждение в актуальном списке этого аккаунта, затем вызывает `IEconService/GetTradeOffer` с `get_descriptions=true`.
- Проверяет ID предложения и состояние ожидания подтверждения. Описания сопоставляются по `appid`, `classid`, `instanceid`; ID остаются строками, количество не теряется. Предметы без описаний сохраняются в списке с идентификатором и заглушкой.
- Пустой с обеих сторон, завершённый или некорректный ответ не выдаётся за корректный состав обмена. При недоступности Economy API доступен повтор или переход к самому предложению в Steam. Ошибка Economy API не сбрасывает работающую сессию mobileconf.
- Подробности не загружаются фоновым poller: запрос выполняется при раскрытии трейда. Поздние ответы после закрытия, смены аккаунта, workspace или блокировки не отображаются.
- В webview не вставляется HTML Steam. Изображения загружаются по HTTPS с публичных CDN Steam без referrer. Ошибка изображения не блокирует текст и действия. Состав не используется для автоматического разрешения трейдов; прежняя проверка исходящего предложения сохранена.

Первичные источники протокола: [Steamworks IEconService](https://partner.steamgames.com/doc/webapi/IEconService), [node-steamcommunity: поля mobileconf](https://github.com/DoctorMcKay/node-steamcommunity/blob/master/components/confirmations.js), [node-steam-tradeoffer-manager: GetTradeOffer и descriptions](https://github.com/DoctorMcKay/node-steam-tradeoffer-manager/blob/master/lib/index.js).

## Проверки

- `npm run build`: TypeScript и Vite проходят.
- `npm test`: 7 проверок, включая разрешённые CDN, отклонение посторонних/локальных URL, OTP, блокировку и смену workspace.
- `cargo test --locked --manifest-path src-tauri/Cargo.toml --no-fail-fast -- --test-threads=1`: 66 тестов. Новые случаи проверяют обе стороны трейда, количество, точные ID, составной ключ описания, отсутствие картинки/описания, завершённое/чужое предложение и некорректный ответ.
- Визуальная проверка в браузере: главная страница, карточки/строки, меню и фокус с клавиатуры, Steam Guard, формы, настройки, RU/EN, размеры 760×520 и 1000×720. Проверены изображение продажи, раскрытие обмена, заглушка сломанной картинки, выборочное подтверждение, пустая очередь, ошибки деталей/сессии и блокировка.
- Повторяемая проверочная оболочка: `npm run build`, затем `python tests/ui/serve.py`, адрес `http://127.0.0.1:18743`. Параметр `scenario`: `empty`, `details-error`, `session-error`, `locked`, `broken-images`. Все IPC и аккаунты синтетические; настоящие операции Steam не выполняются. Единственная внешняя картинка — публичное изображение кейса Steam.

## Ограничения проверки

Живые продажи и обмены не подтверждались; реальные учётные данные не использовались. Наличие описаний и доступ к Economy API зависят от ответа Steam. Приложение явно показывает недоступность данных, а не подставляет предполагаемый состав. Предыдущие исправления v0.2.3 входят в новую сборку.
