# Перенос согласованного оформления — v0.2.5

20 сентября 2026. В приложение перенесён вариант `work/visuals/shadow-fluent.html`: компактные плитки, Departure Mono, тёмные полупрозрачные поверхности, зелёный акцент и редкие плавающие частицы. Предыдущие исправления backend сохранены.

## Поведение

- Основная плитка занимает 228×180 px. Внутри — аватар, имя/логин, избранное, 2FA с таймером и копированием актуального кода, готовность/Sandbox, последний запуск и счётчик, запуск/остановка, игры, подтверждения и состояние доступа. Для длинных имён есть многоточие и полное имя в подсказке. Ошибки готовности могут увеличивать высоту плитки.
- Нет отдельной большой панели выбранного аккаунта. Список и поиск сохранены. При переходе к подтверждениям из плитки сразу выбран соответствующий аккаунт; навигация приложения открывает общую очередь.
- Если подтверждения ещё не загружались, плитка показывает `—`, а не предполагаемый ноль. Ошибка обозначена `!` и доступна в подсказке и в разделе подтверждений. Код и операции копирования отсутствуют при заблокированном хранилище.
- Автовход отображается по реальному состоянию сохранённого пароля. Управление доступом, импорт/экспорт и восстановление сессии остаются в Steam Guard. Изображения предметов и состав обменов сохранены.
- Настройки оформления сохраняются локально: плотность стекла, частицы, их яркость, анимация. Шрифт и лицензия включены в сборку; внешняя загрузка шрифтов не нужна.
- Частицы используют CSS transform/opacity; React не обновляется каждый кадр. Их движение останавливается при скрытом документе, выходе слоя за видимую область, отключённой анимации или системном `prefers-reduced-motion`.
- Меню и диалог подтверждения вынесены в portal на `document.body`, чтобы backdrop-filter карточки не превращал её в ограничивающую область для fixed-элементов. Управление клавиатурой и защита удаления сохранены.

## Проверки

- `npm run build`: TypeScript и Vite проходят, шрифт включён как локальный WOFF2.
- `npm test`: 7 тестов проходят, включая срок действия/копирование 2FA, блокировку, смену workspace и допустимые источники изображений.
- `npm run tauri build -- --no-bundle`: release-сборка Windows x64.
- В браузере проверена сборка приложения через существующую оболочку `tests/ui/serve.py`, а не HTML-эскиз. Размеры viewport: 1000×720 и 760×520.
- Проверены размеры и отсутствие горизонтального переполнения плиток/строк, RU/EN, длинное имя, аватары, работающий Sandbox, маршрут к подтверждениям конкретного аккаунта, изображение продажи и раскрытие состава обмена.
- Меню целиком помещается в минимальном окне; диалог удаления открывается поверх интерфейса и сохраняет ввод логина/отключённую кнопку подтверждения. Удаление не выполнялось.
- Проверены отсутствие кода при блокировке, переход к разблокировке из плитки, выключение частиц и анимации, изменение плотности стекла и сохранение настроек после перезагрузки.
- Визуальный браузерный тест использует синтетические аккаунты и IPC. Настоящие входы, запуски Steam, продажи и обмены не выполнялись. Нативный процесс приложения во время проверки не запускался.

Для сохранения собственных цветов в браузерном предпросмотре добавлен документированный [`darkreader-lock`](https://github.com/darkreader/darkreader/blob/main/CONTRIBUTING.md#disabling-dark-reader-on-your-site); расширение Dark Reader иначе переопределяло прозрачность и цвета. Это не меняет настройки расширения пользователя.
