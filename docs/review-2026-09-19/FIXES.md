# Исправления v0.2.3 — 19 сентября 2026

Исправлены пункты 01–23 исходного [ревью](REVIEW.md), замечания по UI и накопление backups. Исходное ревью и воспроизведения сохранены как исторические материалы: они описывают состояние **до исправлений**.

| Пункты ревью | Что изменилось | Проверка |
| --- | --- | --- |
| 01, 09, 12 | Перенос отклоняет вложенные пути и занятую папку аккаунтов. Сначала создаётся проверенная копия, затем переключаются настройки; исходные аккаунты сохраняются в одном архивном каталоге. Небезопасные имена и повторное добавление отклоняются. | Тесты переноса, коллизий, имён, сохранности метаданных и политики шифрования. |
| 02–04 | Политика шифрования хранится в workspace. Любая запись в закрытое хранилище запрещена. Старый пароль проверяется до замены ключа; смена ключа использует журнал и откат. Старые plaintext-файлы при включённом шифровании исправляются после разблокировки. | Неверный пароль, повреждённый второй файл, сбой посреди записи, восстановление после перезапуска, отдельные ключи рабочих папок. |
| 05 | Импорт, вход и работа с подтверждениями проверяют логин и известный SteamID. UI показывает идентификаторы импортированного аутентификатора и ошибку несоответствия. | Проверки другого логина, другого SteamID и совпадения без учёта регистра. |
| 06, 16 | Секреты сохраняются до активации; результат активации — до ответа UI. Есть защищённая DPAPI копия для восстановления мастера, продолжение после перезапуска и отдельная отметка о записанном коде восстановления. Повторы Finalize ограничены пятью последовательными запросами. | Тест полного локального восстановления; UI с двумя ответами `want_more`, затем успехом, и проверкой Escape. |
| 07, 08, 17 | Удалены созданные приложением правила общего доступа к Steam-конфигам и глобальным объектам. Конфиг и AutoLoginUser готовятся внутри выбранной песочницы. Host Steam завершается по пути/PID и проверке принадлежности Sandboxie. Новые имена box учитывают знаки пунктуации, существующий профиль используется по владельцу. | Тест миграции правил, владельцев и уникальности имён. Параметры процесса сверены с исходниками Sandboxie. Реальный запуск/остановка Steam не выполнялись. |
| 10 | Ошибки HTTP при привязке не содержат URL с access token; ошибки разбора не включают тело ответа. | Тест отсутствия секрета в ошибке и проверка ветвей обработки ошибок. |
| 11 и backups | VDF и AutoLoginUser хранятся в одном файле. Откат выбирает эту согласованную точку. До 10 точек, соседние повторы одинакового состояния пропускаются. Старые пары преобразуются, `PATCHED` удаляются. | Тест миграции 15 пар, выбора оригинала, лимита, дедупликации и сохранения постороннего файла. Очистка реальной папки выполнена. |
| 13, 18 | Блокирующие Tauri-команды вынесены с UI-потока. OTP рассчитывается локально; синхронизация времени работает отдельно, с таймаутом и паузой после ошибки. Сетевые операции сериализуются для одного аккаунта, независимые аккаунты имеют разные блокировки. | Сборка Tauri, тесты сессий и независимости блокировок. |
| 14 | Код скрывается по фактическому сроку действия; перед копированием запрашивается актуальный код. Закрытие хранилища сразу очищает секреты в UI. | Тесты границы срока, паузы UI, копирования и позднего ответа после блокировки. |
| 15 | Выбор в импорте не зависит от периодических обновлений родительского экрана. | UI: снятая галочка сохраняется после нескольких циклов опроса sandbox. |
| 19 | Выбор игры использует общий путь запуска: проверку прав и предупреждение о работающих играх. | Проверка связей обработчиков и UI предупреждения. |
| 20 | UI различает отсутствие пароля, готовность к автовходу, паузу, отклонённый пароль и недоступность DPAPI. После ошибок состояние обновляется с диска. | Тесты сохранения, пауз, отключения и удаления пароля; UI восстановления сессии. |
| 21 | «Проверить сейчас» выполняет отдельный опрос даже при выключенном фоне; этот ручной опрос не запускает автоматическое подтверждение. | Проверка ветки `check_now`, UI при отключённом фоне. |
| 22 | Ответы UI имеют поколение workspace, IPC передаёт ожидаемую папку, события содержат workspace. Смена папки дожидается текущих операций и сбрасывает ключи/сессии. | Тесты поздних ответов OTP/подтверждений после смены папки. |
| 23 | При ошибке настроек есть явный экран с повтором и восстановлением. Сохраняется предыдущая валидная версия и копия повреждённого файла. | Rust-тест восстановления и тест состояния загрузки во фронтенде. |

Дополнительно исправлена команда остановки выбранной песочницы: `/terminate_all` заменена на `/terminate`. По [документации Sandboxie](https://sandboxie-plus.github.io/sandboxie-docs/Content/StartCommandLine/) первый вариант завершает процессы всех песочниц. Проверка PID использует [SbieApi_QueryProcess](https://github.com/sandboxie-plus/Sandboxie/blob/master/Sandboxie/core/drv/process_api.c).

UI: изменяемый размер окна (по умолчанию 1000×720, минимум 760×520), более крупные элементы управления, видимый фокус, удержание фокуса в диалоге и его возврат, Escape с учётом состояния операции, подписи полей, сохранение выбранного языка. Восстановление 2FA и обслуживание backups доступны из интерфейса.

Реальные трейды, привязка/снятие 2FA в Steam, остановка игр и работа изменённой изоляции с драйвером Sandboxie не проверялись на пользовательских аккаунтах. Это не обещание совместимости с любыми изменениями Steam API. Старую запущенную версию нужно закрыть перед запуском v0.2.3: она продолжит создавать backups по прежней схеме.

Сохранённый пароль защищён Windows DPAPI для текущего пользователя; экспорт `.maFile` его не содержит. Для автоматического входа нужны доступные секреты Steam Guard; заблокированный master vault требуется разблокировать. Если Steam требует почту или дополнительную проверку, приложение переводит вход в ручной режим.
